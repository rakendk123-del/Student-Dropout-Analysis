# 🎓 Student Dropout Analysis Dashboard

### 📊 Analyzing Student Dropout Patterns Using Power BI

## 📌 Project Overview

The Student Dropout Analysis Dashboard is a data analytics project developed using Microsoft Power BI. The main objective is to explore student dropout patterns and understand how academic performance, attendance, study habits, stress levels, and other factors relate to student outcomes.

This project transforms student data into interactive visualizations to make patterns easier to identify and understand.

## 🎯 Project Objectives

* Analyze student dropout status.
* Explore the relationship between attendance and academic performance.
* Understand how study hours relate to student outcomes.
* Examine the relationship between stress levels and dropout status.
* Compare academic performance across departments.
* Present meaningful findings through an interactive Power BI dashboard.

## 🛠️ Tools and Technologies

| Tool               | Purpose                                      |
| ------------------ | -------------------------------------------- |
| Microsoft Power BI | Dashboard development and data visualization |
| Microsoft Excel    | Dataset storage and data preparation         |
| Power Query        | Data transformation and preparation          |
| Data Analytics     | Exploring patterns and identifying insights  |

## 📂 Dataset Description

The project uses a student dataset containing information about academic performance, attendance, personal circumstances, and dropout status.

### Key Features

* **Student Information:** Age, gender, and department
* **Academic Performance:** GPA, semester GPA, and CGPA
* **Attendance:** Attendance rate and attendance status
* **Study Habits:** Daily study hours and assignment delays
* **Well-being:** Stress index and stress level
* **Financial Background:** Family income and scholarship information
* **Student Outcome:** Active or dropped-out status

## 📈 Key Areas of Analysis

### 1. Student Dropout Analysis

Explore the distribution of active students and students who have dropped out.

### 2. Attendance Analysis

Examine attendance patterns and compare attendance rates between student groups.

### 3. Academic Performance Analysis

Compare GPA and CGPA values to identify differences in academic performance.

### 4. Study Habits Analysis

Explore how daily study hours and assignment delays relate to student outcomes.

### 5. Stress Level Analysis

Investigate differences in stress levels between active students and students who have dropped out.

### 6. Department-Wise Analysis

Compare student outcomes across departments to identify areas that may need further investigation.

## 🔍 Key Insights

The analysis focuses on identifying patterns in student attendance, academic performance, study habits, and stress levels.

The findings can help highlight areas where additional student support may be worth investigating.

*The final insights should be based on the verified results displayed in the Power BI dashboard. Observed relationships do not necessarily mean that one fact*
